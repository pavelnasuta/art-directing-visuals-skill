# Art-directing visuals

Практический skill для создания постеров, обложек, баннеров и социальных визуалов. Помогает превратить сообщение в один ясный визуальный замысел, не потерять точность фактов и проверить финальный файл перед публикацией.

## Что внутри

- выбор идеи, а не набора декоративных стилей;
- работа с аудиторией, каналом, форматом и обязательным текстом;
- границы по авторским правам и использованию референсов;
- запрет на выдуманные факты, даты, цифры, людей, логотипы и обещания;
- проверка читаемости, точности копирайта и визуальных артефактов.

## Пример задачи

> Подготовь обложку для статьи о том, как команда проверяет AI-автоматизацию. Аудитория — продуктовые команды, формат — 1200×630, заголовок должен быть точным.

Skill сначала определит сообщение и ограничения, затем выберет один предметный визуальный ход, подготовит композицию и проверит текст, контраст, факты и права на материалы.

## Границы

Skill не заменяет дизайн-систему, UX-дизайн или полноценный бренд-процесс. Он предназначен для самостоятельного визуального актива. Референсы — источник вдохновения, а не разрешение копировать чужую работу. Перед публикацией проверьте права на изображения, шрифты, товарные знаки и лица.
